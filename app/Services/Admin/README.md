# 🛡️ Domain Services: Admin

Layanan bisnis khusus untuk **Administrator Klinik** dalam mengagregasi analitik operasional dan mengelola konfigurasi sistem klinik.

## 📁 Subfolder & File Service:
- **`Analytics/AnalyticsAdminService.php`**: Perhitungan ringkasan pengunjung unik, konversi booking, sumber trafik, dan grafik tren harian.
- **`Settings/ClinicSettingAdminService.php`**: Penyimpanan dan pembacaan konfigurasi global klinik.
