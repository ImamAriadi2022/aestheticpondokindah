# 🌐 Domain Model: Guest (Public Info)

Menyimpan model data untuk konten informasi edukasi dan pemasaran klinik yang dapat diakses publik.

## 📁 Subfolder & File Model:
- **`Service/ClinicService.php`**: Katalog layanan perawatan gigi (deskripsi, estimasi langkah, dokter penanggung jawab).
- **`Faq/Faq.php`**: Tanya jawab umum seputar klinik dan gigi.
- **`Contact/ContactMessage.php`**: Pesan masuk dari form kontak publik di landing page.
- **`Content/`**:
  - `Post.php`: Artikel blog & tips kesehatan gigi.
  - `Promo.php`: Banner voucher diskon perawatan.
  - `Popup.php`: Pengumuman popup modal di halaman web.
  - `GalleryItem.php`: Foto suasana fasilitas & klinik.
  - `Testimonial.php`: Ulasan dan cerita kepuasan pasien.
- **`Wilayah/Wilayah.php`**: Master data kode dan nama provinsi, kabupaten, kecamatan, dan kelurahan Indonesia.
