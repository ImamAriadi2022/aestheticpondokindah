# 🛡️ Domain Model: Admin

Menyimpan model data yang dikelola secara eksklusif oleh Administrator Klinik untuk operasional dan monitoring.

## 📁 Subfolder & File Model:
- **`Settings/ClinicSetting.php`**: Konfigurasi global sistem berupa key-value (WhatsApp CS, T&C, biaya, email).
- **`Analytics/PageVisit.php`**: Log analitik pengunjung web (IP, User-Agent, referer, durasi).
- **`DownloadApp/DownloadApp.php`**: Manajemen link unduhan aplikasi mobile Android & iOS.
- **`Media/Media.php`**: Arsip metadata berkas dan dokumen yang diunggah ke sistem.
- **`PromoClaim/PromoClaim.php`**: Catatan riwayat penggunaan voucher diskon promo oleh pasien.
