# 🔗 Domain Controller: Shared (Interaksi Multi-Aktor)

Domain ini menampung controller untuk fitur-fitur yang menjadi **titik temu dan interaksi antara lebih dari satu aktor** (Admin, Dokter, Pasien, dan Tamu).

## 📁 Subfolder Fitur:
- **`Auth/`**: Autentikasi lintas aktor (Login semua role, Registrasi pasien baru, Session Me, Logout).
- **`User/`**: Profil pengguna mandiri dan manajemen master pengguna oleh Admin.
- **`Branch/`**: Katalog cabang klinik untuk publik serta CRUD cabang oleh Admin.
- **`Wilayah/`**: API master data wilayah Indonesia untuk form pendaftaran dan profil.
- **`Media/`**: Handler upload berkas gambar dan dokumen untuk seluruh aktor.
