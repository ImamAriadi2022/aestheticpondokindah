# 👤 Domain Controller: Patient

Domain ini menangani seluruh endpoint untuk **Pasien Terdaftar** dalam mengakses layanan klinik secara mandiri.

## 📁 Subfolder Fitur:
- **`Membership/`**: Informasi tier keanggotaan, saldo poin reward, riwayat transaksi, dan integrasi pembayaran upgrade via Midtrans Gateway.
- **`Billing/`**: Daftar invoice perawatan klinik dan riwayat konfirmasi pembayaran.
- **`Reservation/`**: Pembuatan reservasi janji temu dokter mandiri dan pembatalan reservasi.
- **`Consultation/`**: Telekonsultasi chat dan video call dengan dokter klinik.
- **`Complaint/`**: Pengajuan tiket keluhan/komplain dan pelacakan respons admin.
- **`Notification/`**: Notifikasi in-app dan registrasi token FCM device.
