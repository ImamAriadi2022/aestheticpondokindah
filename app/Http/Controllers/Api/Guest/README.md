# 🌐 Domain Controller: Guest (Publik)

Domain ini menyediakan endpoint **Akses Terbuka Tanpa Login** untuk calon pasien, pengunjung website, dan tamu.

## 📁 Subfolder Fitur:
- **`Service/`**: Katalog lengkap layanan perawatan gigi medis dan spesialisasi.
- **`Faq/`**: Tanya jawab seputar perawatan gigi dan reservasi.
- **`Contact/`**: Formulir kirim pesan pertanyaan tamu ke kotak masuk admin.
- **`Content/`**: Artikel blog edukasi, promo aktif, galeri klinik, dan testimoni.
- **`Reservation/`**: Booking reservasi cepat bagi tamu non-login.
- **`Consultation/`**: Konsultasi telemedisin tamu via nomor token unik.
- **`Analytics/`**: Pelacakan anonim statistik kunjungan halaman web.
- **`Settings/`**: Pengaturan publik (nomor WhatsApp official, jam operasional).
- **`About/` & `Legal/`**: Informasi profil klinik, Kebijakan Privasi, dan Syarat Ketentuan.
