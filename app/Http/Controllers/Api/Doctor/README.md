# 🩺 Domain Controller: Doctor

Domain ini berisi controller khusus untuk **Praktik Medis Dokter Gigi** dan sistem **Rekam Medis Elektronik (EMR)**.

## 📁 Subfolder Fitur:
- **`Schedule/`**: Pengaturan jadwal praktik dokter mandiri dan kuota per sesi.
- **`Queue/`**: Antrean pasien harian yang datang ke klinik berdasarkan reservasi.
- **`Consultation/`**: Telekonsultasi live chat, Google Meet link, dan rekap pasien.
- **`Visit/`**: Pencatatan kunjungan fisik pasien di ruang periksa.
- **`MedicalRecord/`**: Rekam medis elektronik (EMR), catatan SOAP, finalisasi, dan penguncian rekam medis.
- **`Diagnosis/`**: Penetapan diagnosis klinis dengan kode standar ICD-10.
- **`Procedure/`**: Tindakan medis gigi (scaling, tambal, cabut, behel, dll.) dari katalog tindakan.
- **`Odontogram/`**: Pemetaan kondisi anatomi 32 gigi pasien secara visual dan interaktif.
