# 🛡️ Domain Controller: Admin

Domain ini berisi controller untuk seluruh fitur **Panel Administrasi Klinik**, mencakup operasional reservasi, monitoring konsultasi, manajemen keanggotaan, pengaturan sistem, dan konten informasi.

## 📁 Subfolder Fitur:
- **`Analytics/`**: Laporan ringkasan metrik kunjungan, reservasi, dan pasien.
- **`Settings/`**: Pengaturan global klinik (WhatsApp CS, jam kerja, biaya layanan).
- **`Reservation/`**: Penjadwalan, konfirmasi, dan pembatalan reservasi pasien.
- **`Consultation/`**: Monitoring antrean konsultasi, transfer ke dokter, dan penutupan tiket.
- **`Membership/`**: Validasi upgrade membership, konfirmasi pembayaran manual, dan poin.
- **`Complaint/`**: Pengelolaan dan balasan atas komplain pasien.
- **`PromoClaim/`**: Verifikasi dan klaim promo pasien di kasir/admin.
- **`PublicInfo/`**: CRUD katalog layanan medis, FAQ, pesan kontak masuk, profil tentang klinik, dan dokumen hukum.
- **`Content/`**: CRUD postingan blog, banner promo, popup pengumuman, galeri, dan testimoni.
- **`DownloadApp/`**: Pengaturan tautan aplikasi mobile (Play Store / App Store).
