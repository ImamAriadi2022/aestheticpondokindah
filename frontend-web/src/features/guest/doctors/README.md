# Doctors

Public doctor directory and doctor schedule management.

## Used By

- Guest
- User (Patient)
- Doctor
- Clinic (Admin)

## Components

- `DoctorCard` - doctor directory card (public)

## Services

- `publicDoctorScheduleApi` - public doctor schedules
- `doctorScheduleApi` - doctor-owned schedule management
- `adminDoctorScheduleApi` - clinic-admin schedule management
